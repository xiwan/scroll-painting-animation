# 布局：功能团、疏密、选图、每张图都用上

零件：`scrollkit.DistrictField`、`scrollkit.SpritePicker`；完整例子：`assets/districts.qingming.json`。

## 1. 功能团（"团"而不是"带"）

沿卷轴排若干团：`[(名, u0, u1), ...]`。三个手段让它不机械：

1. **软边**：相邻团在 `edge`（约 4 秒镜头）宽的过渡带里按权重混合。
2. **扭曲边界**：u 先加一个随 (u, v) 变化的扰动（几百单位），团的边缘歪歪扭扭，纵深方向上也不齐。
3. **硬边界**：城墙这类必须分明的，用 `clamps` 把墙内点的 u 夹到"城内团"区间、墙外夹到"城外团"区间。

每团一份档案（profile）：

| 键 | 含义 | 《清》的取值范围 |
|---|---|---|
| dens | 地块真正起房的概率（其余做菜园/空场/树） | 郊野 .55，深巷 .72，桥头/城内商业 .98–1 |
| gap | 排屋行距系数 | 商业 .45，郊野 1.2，官府 1.8 |
| kinds | 房屋类型比例（铺面/酒楼/茶坊/住宅/两层宅/仓/农舍） | 商业 shop .6，深巷 res .5 + res2 .4 |
| light | 夜里灯火系数（门前光、灯笼、亮窗都乘它） | 商业 1.0，深巷 .45，官府 .35 |
| 院落/大宅概率 | 街坊布局 | 官府区院落 .55，深巷大宅 .25 |

临主街的地块（街市主街两侧）铺面、酒楼、茶坊的比例再 ×2.5。

## 2. 疏密节奏

先定"每 10 秒房屋数"的目标曲线，再调档案，最后**统计核对**（demo 的 `stats`、正式项目的 dstat 脚本）：

```
郊野 2–4 → 近郊 4–8 → 河边草市 10–14 → 码头 16–20 → 桥头 28–34（最密）→ 城外街市 18–22
→ 城门外 12–16（刻意留空）→ 城内商业 30–36 → 娱乐+住宅 24–28 → 深巷大宅 18–22 → 寺观官府 14–18
```

密度不够时的旋钮（按效果从大到小）：起房概率、行距、地块进深阈值（v3 只在进深 >175 时加背排，
密团里放宽到 140）、跳过规则（远离河的地块是否留给田野）。

**空地不要空着**：菜园（村郊、深巷、官府）、空场 + 一两棵树、井、草垛。留白是疏密感的来源。

## 3. 选图

两层：先按功能团抽**房屋类型**（kinds），再在这个类型能用的图里按**亲和度**挑一张。

```
groups   = {用途组: [图...]}        如 eatery: [食肆a, 食肆b, 面馆a, 面馆b, 饼铺]
kinds    = {用途组: {能充当的类型}}   如 eatery: {tavern, tea, shop}
affinity = {团: {用途组: 亲和度}}      如 bridge: {eatery 1, tavern 1, tea 1, daily .8, ...}；0 = 这团不出现
```

- 防重复：同一张图在 360 单位内每多一次，权重 ×0.2（"复制粘贴感"主要来自相邻重复）。
- 首次出场加权 ×3。
- 体量约束：大院落/长仓只进大地块；小棚屋在大地块降权（否则缩成"模型"或撑成"巨棚"）。

## 4. 每张图都用上

1. 选图时首次出场加权（大多数图自然会出场）。
2. 建完场景后补位：还没出场的图，找一栋**同类型、所在团亲和度最高、且那张图用了不止一次**的房子换掉。
3. 地标、专门建筑（指定图放置的）也算出场；画进合成精灵里的（宝塔之类）按缓存判断。
4. **最后统计核对**：素材目录里所有 `bld_*` 与画面里实际出现的逐张对比，打印未出场列表——必须为空。

补位找不到位置的，通常是体量约束太严或亲和度全为 0：给它在合适的团里**专门放一处**（例如长仓放在码头卸货场旁）。

## 5. 地标与专门建筑

- 地标先放（占位优先），位置用"街坊坐标"或"沿主街第 k 段的 f 处"给，放不下要打印警告。
- 地标所在街坊不再抽"大宅"之类的整块布局（否则永远放不下，静默退化）。
- 每个功能团配一两个"点题"的专门建筑：郊野的茶棚/村塾/水磨坊/坟茔，码头的官仓/邸店，城内的瓦子勾栏、谯楼与照壁。
- 有方向要求的（水磨坊的水轮要贴着河）：先想清楚精灵哪一面朝哪，再选河段、选正面朝向。

## 6. 改布局后的回归

布局改动会连带别的东西消失（风筝、孩童、某个地标）。每次改完跑特征清单：题签全在、风筝数、各类闲立人数、
船数、每张图出场次数，与上一版对比。
