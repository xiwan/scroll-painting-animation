# 验证工具、症状速查、回归清单

## 1. 工具

| 工具 | 用途 |
|---|---|
| `scroll_demo.py stats` / 项目里的统计脚本 | 每 10 秒房屋数、主导功能团、题签时刻、每张图出场次数、空地数 |
| 引擎 `preview <秒...>` | 只看改动处的 2–4 帧（JPEG） |
| 孤立测试 | 把一个对象在空白画布上按一组参数画一排（例：船在 9 个角度、4 个过弯位置），排除场景干扰 |
| `frame_grid.py` | 成片抽帧拼图（`a:b:步长`、`--crop` 做跟拍条），长边 ≤1900 |
| `contact_sheet.py` | 新素材对照表 |
| `popcheck.py` | 逐帧跳变：0 离群才算过（关键帧、淡入淡出已排除） |
| ebur128 | 音轨响度与真峰值 |
| AST 标签（`sfx_mmaudio.py tag`） | 声音和画面对不对得上 |

**看图限制**：单张 ≤8000 像素、≤5MB；一次放多张时任意一边 ≤2000 像素（拼三帧对比条很容易 2040 宽被拒）。
所有拼图工具都把长边控制在 1900。

## 2. 症状速查（都来自实际项目）

| 症状 | 原因 | 处理 |
|---|---|---|
| 船过弯叠影 / "中间过程怪" | 交叉淡化、连续剪切、扫换 | 三张朝向图硬切；船底对齐（motion.md §2） |
| 题诗背后没雾、字压在田垄上 | 椭圆参数顺序写错，alpha 为 0 | `(cx, rx, cy, ry)`；加单元检查衬雾 alpha |
| 题诗错字 | 手抄 | 逐字核对原文 |
| 船上的人飘在空中 | 甲板偏移不对 | 逐个调，跟拍条看 |
| 桥上抛下的缆绳看不见 | 被桥面分层切掉 / 颜色和桥拱一样 | 单独一层画在桥栏之上；描边 + 浅芯 |
| 土路拐角缺贴图 / 硬边方块 | 条带只沿直段 | 拐角单独成块、车辙沿圆弧 |
| 城市石板路拼接生硬 | 全图一个方向采样 | 按街道走向铺、宽街贯通、交界接缝；空地加夯土纹理 |
| 城墙顶面没有砖 | 顶面只填平色 | 顶面也贴砖（砖行顺墙走） |
| 房子"复制粘贴" | 图太少、相邻重复 | 每用途两个种子出图 + 防重复降权 + 每张图都用上 |
| 某个地标永远放不下（静默退化） | 地标街坊被别的东西先占 | 地标街坊不抽整块布局；放不下要打印 |
| 改布局后风筝/孩子消失 | 单一随机数流 + 放置条件太严 | 子系统独立 RNG；回归清单；放宽条件（田里也可） |
| 夜里红柱子像霓虹 | 灯笼按颜色阈值选 | 连通块形状筛选 |
| 夜色挡住题诗 | 夜色染了整个云气层 | 保护图；还没写的先随夜色 |
| 卷首题字没和雾衬对齐 | 雾衬中心偏 | 以整组字为中心 |
| 顶部白雾太均匀 | 一条连续渐变带 | 一维噪声控制有无与厚薄 |
| 音效出成配乐 | 画面戏剧化 | 候选 + 打分（audio.md §4） |
| 音频峰值 +3dB | 相同双声道下混测量 | 用 ebur128 true peak |
| 远端命令突然全失败 | SSM 会话闲置断开 / /tmp 被系统清理 / GPU 机重启后驱动没加载 | infra.md |

## 3. 回归清单（每次改布局或大改后过一遍）

- [ ] 题签列表与时刻（全部还在，顺序对）
- [ ] 风筝数、孩童/乞丐/僧侣等母题的闲立人数
- [ ] 船数、名场面跟拍条
- [ ] 每张 `bld_*` 图出场次数（未出场为空）
- [ ] 每 10 秒房屋数曲线与目标对比
- [ ] 夜景发光层统计（房屋数、门前灯数）
- [ ] 抽帧：卷首、每首诗写完时、高潮、入夜中段、黎明、卷尾
- [ ] popcheck 0 离群；音轨 −17 LUFS 左右、真峰值 < −0.5 dBFS

## 4. 交付说明要包括

- 用户点名的每一条：原来就有 / 新加 / 做不到（原因）。
- 每条中途补充的要求怎么处理的（steering 逐条回执）。
- 验证了什么、没法验证什么（例如"声音只做了自动标签核对，没有人耳听"）。
- 许可限制（MMAudio 非商用）。
- 云上机器是否还开着、每小时多少钱，**停不停由用户决定**。
