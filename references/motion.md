# 动态：行人、车马、船、桥、名场面

## 1. 行人与车马

- 沿路网图寻路（街段为边），每人一条路线；端点处淡入淡出。
- **速度分级 + 车道**：快马、狗、步行、负重、老人、牛车各有速度范围和距街心的侧向偏移；同向时快的走里侧，
  各类车道不重叠——不会出现人穿过人、马穿过车。
- 朝向：四方向精灵（正 3/4、背 3/4，左右镜像）；背影图用编辑模型转出来（assets.md §4）。
- 闲立人物：放下后统一做合理性检查——不在水里、不在房屋/墙/摊子占地里、田里只有农人（和放风筝的孩子）。
- 城外人少、城内人多（按功能团给密度）；孩子不单独在郊野路上走（换成大人带着）。

## 2. 船

- 行船沿河道中心线 + 车道偏移；朝向用平滑后的切线（短弦算横向偏移、长弦算朝向，避免过折点时侧跳）。
- **过弯换朝向：直接硬切，不要做中间过渡。** 试过的失败方案：
  - 两张图交叉淡化 → 叠影（两条船重影）。
  - 连续剪切（shear）+ 船头先转的扫换 → 观众说"中间过程太怪"。
  - 正确做法：备三张图（斜向 \、正侧面、斜向 /），按当前船身斜率就近选一张，到阈值（斜率 ±0.289）瞬间切换。
- 换图时对齐：按船底中段（中线两侧各 6% 的列）的最低不透明像素对齐两张图（`scrollkit.bottom_profile`），
  否则切换瞬间船会上下跳。
- 切换不能来回闪：统计每条船每个朝向档位的持续时间，<1 秒的要处理（迟滞或改河道）。

## 3. 桥

- 桥是大件：先占地；桥下过船时把船按桥面切成"桥面下"和"桥面上"两段分别排序。
- 桥上的人、摊贩、看客按桥面的车道走/站。

## 4. 名场面（以"虹桥争渡"为例）

把一句话的画面拆成可执行的动作脚本：

| 时刻（距桥） | 动作 |
|---|---|
| 110 以外 | 桅杆竖着，正常行船 |
| 70–16 | 手忙脚乱放桅（角度插值 + 放到一半时来回晃） |
| 110–26 | 桥上看客抛下缆绳拴船头（绳子单独一层画在桥栏之上，深色描边 + 浅麻色芯，否则压在褐色桥拱上看不见） |
| 全程 | 船顶船工挥手吆喝、撑篙顶桥；人物脚要落在甲板/篷顶上（逐个调甲板偏移，飘在空中最出戏） |
| 过桥后 | 桅杆重新竖起 |

验证用"跟拍条"：按时刻裁出船周围一块拼成一排（`frame_grid.py --crop`），逐格看动作是否连贯。

## 5. 放风筝、炊烟、飞鸟

- 风筝：孩子站在空地或田里（田块里也允许），风筝在高处随风摆，线连到手；只在雨停之后那段出现。
- 炊烟：从农舍、铁匠铺烟囱冒，半透明、飘在树梢之上。
- 这类小东西最容易在布局改动后静默消失——列进回归清单。
