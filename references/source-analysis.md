# 读原作：把一幅画（或一个题材）拆成可执行的长卷计划

产出物：一张**时间轴表**（每段几秒、什么功能团、哪些地标/母题、多密、夜里多亮、配什么声音），
后面所有阶段都照着它做。这张表定不下来，不要开始生成素材。

## 1. 场景清单

逐段读原作（长卷从右往左读；横向全景按镜头走的方向读），记三类东西：

| 类别 | 记什么 | 《清明上河图》例 |
|---|---|---|
| 名场面 / 地标 | 有名字、观众会找的东西，记位置先后 | 虹桥争渡、孙羊正店彩楼欢门、十千脚店、赵太丞家、城门驼队、望火楼、税务 |
| 人物母题 | 反复出现的人和动作 | 纤夫、独轮车、太平车、轿子、驴骡驮队、乞丐、僧侣、儒生、赶考书生、抱孩妇人、嬉戏孩童 |
| 环境 | 地形、水系、季节、天气、时辰 | 汴河贯穿、清明细雨、柳林、田畦 |

**用户点名要的条目逐条建表**，交付时逐条回答"原来就有 / 新加 / 做不到及原因"。

## 2. 空间逻辑（决定"团"怎么排）

不要只按画面顺序摆，要弄清**那个社会的空间规律**——疏密、聚团、分区都从这里来。通用问题清单：

- 城乡梯度：野外 → 村落 → 城郊草市 → 城门 → 城内，各段的房屋类型与密度怎么变？
- 交通节点：桥头、码头、城门、十字街口——这些地方最热闹，常有客栈、货栈、酒楼、摊贩。
- 同业相聚：哪些行当扎堆（金银彩帛、医药、作坊、香烛纸马）？
- 主街与巷：临街是铺面还是住宅？（北宋：坊墙已拆，临街设铺，前店后宅）
- 权力与信仰空间：官署、寺观的位置、形制（高墙深院、广场、门楼、照壁），周边有什么（寺前市）。
- 娱乐空间：说书、杂技、戏台在哪（北宋：瓦子勾栏）。
- 夜间：哪里有夜市、哪里早早熄灯。

北宋东京的参考来源：《东京梦华录》（正店 72 户、马行街夜市、潘楼街金银彩帛、相国寺万姓交易、瓦子勾栏）。
别的题材找对应的笔记/方志/研究；查不到就明确告诉用户哪些是按史料推测、哪些是原作所见。

## 3. 时间轴映射

镜头匀速横移：`t_center(x) = (x − VW/2) / speed`，每个东西在画面里停留约 `VW / speed` 秒
（1080p、85.7 单位/秒时约 16 秒）。先定总时长和速度，再把每个功能团、地标、题诗摆到时间上：

- 每个功能团至少占 8–10 秒，否则观众认不出它是"一个区"。
- 高潮放在 55%–75% 处（《清》的虹桥在 76–92 秒）。
- 题诗/小题放在各大段的中段，和地标错开（不要压在名场面上）。
- 昼夜、天气这类全局变化要有过渡段（入夜 17 秒、黎明 16 秒），并与内容挂钩
  （进城后入夜、卷尾天亮 → 首尾呼应）。
- 留出卷首题签、卷尾题跋的位置；卷尾那块往往只在最后 2–3 秒入画。

## 5. 迁移到其他题材

### 5.1 空间逻辑怎么换

| 题材 | 和《清》的差异 | 调整 |
|---|---|---|
| 《千里江山图》类山水长卷 | 建筑少、山水多，**而且地形有高差** | 功能团改成"山脚村/水岸/山腰寺/峰顶"，地面以山石树为主；房屋密度整体 0.2–0.4；夜景可不做，改晨昏。**但先读 5.3——这类题材需要引擎级改造** |
| 《姑苏繁华图》《康熙南巡图》 | 更多城市段、仪仗队伍 | 城内团拆细（商业街、码头、园林、衙署）；增加队伍类动态母题。这类和《清》最接近，改配置就够 |
| 《紫禁城》类礼制建筑群 | 轴线对称、院落嵌套、无商业密度梯度 | 功能团换成"门—院—殿"的序列；建筑平面可取自 OpenStreetMap（注意 ODbL 署名）；密度曲线换成"空旷—列班—空旷"的节律 |
| 《韩熙载夜宴图》类室内叙事 | 不是地理长卷，是分幕 | 镜头仍横移，"功能团"换成"幕"；夜景全程。**室内要墙体剖切、没有地面网格，引擎改动不小** |
| 现代城市/游戏世界全景 | 无原作 | 先写一段"虚构的空间逻辑"（产业区、居住区、商业区、行政区、景点），同样建时间轴表 |
| 欧洲中世纪城镇 | 不同的空间规律 | 广场—教堂—行会街—城门—郊外磨坊；夜里的守夜人、钟楼。另见 5.2 的字和灯 |

### 5.2 换题材时必须动的代码（不是调参数）

`scrollkit.py` 号称题材无关，但有三个零件是为中式题材写的，换题材要改：

| 零件 | 为什么不通用 | 怎么改 |
|---|---|---|
| `lantern_mask()` | 颜色判据默认 `LANTERN_RED`（红橙、饱和），专门认中式红灯笼。欧洲壁灯/火把偏暖黄、现代路灯近白，全落不进去 → 夜里没有灯火 | 传 `color=LAMP_WARM` / `LAMP_WHITE`，或自定 `(亮度下限, g/r 上限, b/r 上限, r-b 下限)`；形状筛的 `max_units` 也按灯具大小改 |
| `draw_seal()` | 朱文方印，只处理 1/2/4 个汉字 | 整体换掉（纹章、蜡封、手写签名），不要只换字 |
| `InkItem.column()` | 竖排右起 = 中式题诗版式 | 横排题材用 `InkItem.row()`（按实际字宽推进）。逐字蒙版本身用字形实测包围盒，拉丁字母也对得上 |

还有两处默认值是《清》180 秒片的：

- `DayNight()` 的 `dusk=(117,134)`、`dawn=(157,173)` 是绝对秒数 → 做 60 秒片不传参就**永远不会入夜**。
  用 `DayNight.for_duration(总秒数)` 按比例生成。
- `DistrictField` 的 `edge=420`、`warp=260` 和 `SpritePicker(rep_r=360)` 是按《清》的世界尺度
  （85.7 单位/秒）标定的。换 `speed` 后 `edge ≈ 4 × speed / cos30`（4 秒的过渡带），`rep_r` 同理按秒换算。

`references/text.md` 整篇只对中国题材成立（繁体楷书、竖排右起、落款钤印、按"字/秒"算速度）。
非中文题材要重写：横排、按词显现、没有印章、落款形式不同。

### 5.3 山水与室内题材的真实门槛

**引擎没有地形**。`Iso` 把世界当平面 `(gx, gy)`，`g2s` 没有高度项；占地系统是网格矩形；
底图烘焙只画草/土/路/石板/河。山水长卷需要的高程、山体互遮挡、云雾分层、山路折返透视，
`scrollkit` 一个零件都没有。同样，室内叙事需要墙体剖切和"没有地面"的排布。

这两类题材是**重写级工作**，不是改配置：要先给 `Iso` 加高度、给排序加基于高度的遮挡、
把底图烘焙换成高程着色。立项时如果用户点名山水题材，先把这件事说清楚再估工期。

### 5.4 画风

画风换了（水彩、像素、工笔），只改素材提示词里的 STYLE 段和底图/雾衬的纸色，引擎不用动。
这一条对画风成立——但不要用它安慰自己说"换题材也不用动引擎"。

### 5.5 时长不是 180 秒时

"每个功能团 ≥8 秒、高潮在 55%–75%" 来自 180 秒的单线性平移。缩放时：

- 功能团下限按比例缩，但**不低于 5 秒**（再短观众认不出这是一个"团"）；
  60 秒片大概只放得下 5–7 个团，别硬塞。
- 10 分钟以上就不该是单幕匀速平移了，考虑分幕 + 幕间停顿，`DayNight` 也要多个循环。
- 昼夜、题诗、音效窗口全部按比例重排，别照抄绝对秒数。
