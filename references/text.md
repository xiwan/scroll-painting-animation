# 卷上的字：题签、小题、题诗、印章、渐显

零件：`scrollkit.InkItem` / `ink_image` / `draw_ink` / `draw_seal` / `mist_blob` / `FontBank`。

## 1. 选诗与文字

- 每个大段配一首**与该段内容和时代相符**的诗（郊野：程颢《郊行即事》；汴河：皮日休《汴河怀古》；
  城内：刘子翬《汴京纪事》）。逐字核对原文（曾把"恣行時"错成"恣行事"）。
- 用原作时代的字体与字形：繁体、楷书（macOS 的楷体在 AssetsV2 里，`find_cjk_font` 会找）；印文用隶书。
- 落款写朝代 + 作者 + 诗题，末尾一方小印（单字：春/漕/市）。
- 题签（地名、店名）也用繁体楷书；店招按原作招牌文字（"治酒所傷真方集香丸"）。

## 2. 版式

- 竖排、右起、自上而下；每字间距 ≈ 1.17 字高；落款字小一号，放在最左列，印章接在落款下方。
- 题诗放画面下方、大段中段，避开名场面；小题放画面上缘；卷首题签 + 仿作题记 + 一首应景诗；卷尾题跋 + 两方印。

## 3. 雾衬（字背后的那团雾）

- 椭圆参数顺序是 `(cx, rx, cy, ry)`——曾经写成 `(cx, cy, rx, ry)`，结果衬雾 alpha 全为 0、字压在田垄上看不清。
- 题诗、卷首、卷尾用"实心"雾衬：中间实、smoothstep 柔边、边界用低频噪声扰乱（不像一个圆盘）；小题用渐淡软椭圆。
- **雾衬以整组字为中心**（卷首：从最左那列诗到签条右边），否则字看起来没和底对齐。
- 顶部云气只作点缀：一维噪声控制一段有一段无、厚薄不一（`top_mist` + `presence_1d`），卷边只留极淡一线；
  均匀的一条白带很假。

## 4. 渐显（逐字晕墨）

- 每个字先以洇开的淡墨出现（模糊 + 膨胀的字形，色偏灰褐），再收成清楚的笔画；前后约 2.5 个字交叠着写。
- 字写完后印章"按"上去：由 1.18 倍缩到原大、由淡到实。
- 开写时刻：条目中心走到画面 80% 处（右侧进来 20%）；速度：诗 8 字/秒，小题 4 字/秒，卷首题签 5.5 字/秒。
- 卷尾题跋往往只在最后 2 秒入画：单独给开写时刻、加快速度（26 字/秒），保证淡出前写完。
- 实现：每块题字画在自己的小图层上，记下每个字的矩形和顺序；没写完时逐字算透明度合成，写完后直接贴整块。

## 5. 夜里不能挡字

- 夜色只作用于画里的景物；卷上的云气按 `DayNight.mist_k` 染成月下青灰。
- **题字衬雾处不压暗**：建一张"保护图"（雾衬 smoothstep × 1.4），夜里乘 (1 − 保护)。
- 还没开写的题字，衬雾先跟夜色走（否则夜里先出现一个空白亮盘）；开写后随进度亮回纸色。
- 题签（小纸条）画在云气之上，不受夜色影响。
